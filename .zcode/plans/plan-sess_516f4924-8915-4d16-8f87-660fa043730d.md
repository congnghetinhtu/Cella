## Target architecture

New module `Cella/AutoMix/` (file-system-synchronized Xcode groups → new files build automatically):

```
Cella/AutoMix/
├── AutoMixModels.swift     PlayMode (.interactive / .mixSet), TransitionPlan, engine events
├── TransitionPlanner.swift Pure, testable planning: wraps Crossfader.computeCrossfadeParams + ports
│                           computeBeatAlignedCrossfadeTime + mood-preservation params +
│                           NEW tempo-sync policy (meet-in-middle ramp, capped 15%, bypassed <3% ΔBPM, no pitch correction)
├── AudioGraph.swift        Node graph: deckA/deckB (player+timePitch+EQ) → mixer → profileEq → surroundEq →
│                           hallReverb → peakLimiter → mainMixer, stereo-width tap; Orquesta FX API preserved
├── Deck.swift              One deck: file-backed scheduling (scheduleFile/scheduleSegment — NO whole-track
│                           PCM loads), small cue buffers only (<2s), sample-clock position
├── AutoMixEngine.swift     Playback core: load/play/pause/seek, transition(to:plan:) sample-accurate at the
│                           target bar (AVAudioTime), ONE sample-clock automation ticker (replaces 9 wall-clock
│                           timers), completion via buffer handlers + watchdog
├── MixDirector.swift       Orchestrator: owns queue + mode, plans one transition ahead, replans on queue
│                           mutation, auto-advance in mixSet, event stream (track changed / transition / analysis)
└── AnalysisService.swift   TrackAnalyzer wrapper: priority analysis (current → next → rest), progress events,
                            .cellax cache warming on every import
```

**Kept nearly as-is:** `MixEngine` (compatibility + 2-opt ordering), `Crossfader`, `TrackAnalyzer`, `AnalysisCache`, `AudioHelpers`, `MixQueue`, all models, all UI, "Blend to" UX (renamed from "OpenMix to").

**Mix-set semantics:** no pre-render — the set is performed live; next transition planned when the current track starts, executed at the computed bar boundary; seek/skip always work (skip = execute planned transition now).

**Memory/timing fixes:** crossfades no longer load 3× full-track PCM; position from player sample clock (no wall-clock drift); track end via schedule completion, not timers.

## Risks & mitigations

- Volume automation: single sample-clock-locked 5ms ticker, centralized
- Future bar scheduling: verify AVAudioTime landing; fallback = cue buffer with silence padding (existing pattern)
- TimePitch artifacts: cap 15%, auto-bypass <3% ΔBPM
- Scope guard: EnhancedLRC standalone player, EPUB, Cluster UI untouched
